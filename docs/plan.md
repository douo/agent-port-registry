## 服务接入模板

每个新服务由 Agent 完成一个垂直闭环：

1. 定位默认配置来源；
2. 向目标节点本地 APR ensure；
3. 写入固定端口；
4. 登记完整元数据；
5. 启动并做健康检查；
6. 在主节点 Web UI 通过 SSH 快照验证项目、端口、进程和本机转发。

若服务已有 APR 固定配置，跳过 2 和 3，直接正常启动。
